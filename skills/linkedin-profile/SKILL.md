# Profile audits and rewrites

Use the shared scope and factual rules in the [master skill](../../SKILL.md).
This module can be read directly but requires the repository references.

## Inputs

Profile text/screenshots and goal: career, authority, clients or another user-defined outcome.

## Workflow

1. Identify the intended reader and goal. Read actual sections supplied; label missing sections unassessed rather than guessing from the URL.
2. Review clarity of positioning, headline, About opening/body, evidence in experience, relevant skills, featured work, contact path and visible design.
3. If a score is requested, use the documented 12-part rubric linked in engagement-and-analysis.md and show assessed points and unassessed areas. Do not present it as a LinkedIn score or conversion forecast.
4. Prioritize gaps, then provide before/after rewrites grounded in genuine work and achievements. Match featured suggestions to the goal; do not force sales copy on a student or job seeker.
5. Review voice and factual accuracy. Re-score only changes actually demonstrated; a rewrite cannot supply a missing photo, recommendation or work sample.
6. Deliver manual-copy sections. A request to improve a profile does not authorize modifying the live account.

## Deliverable

Prioritized audit, clearly qualified score if requested, copy-ready rewrites and remaining evidence/assets needed.
