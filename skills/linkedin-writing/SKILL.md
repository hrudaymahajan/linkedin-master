# Posts, hooks and repurposing

Use the shared scope and factual rules in the [master skill](../../SKILL.md).
This module can be read directly but requires the repository references.

## Inputs

Topic or source asset, audience and requested deliverable; use existing voice preferences.

## Workflow

1. Identify one central claim and its evidence. Read a supplied source before extracting material. Choose an educational explanation when no personal experience is confirmed.
2. For hook analysis, label the source's opening, promise, supporting structure and close, then produce a blank reusable structure. Describe plausible effects without asserting why a post went viral.
3. For drafting, consult the two hook libraries in content-methods.md only as needed. Jake's 21 IDs and Sergey's 20 IDs are separate namespaces with overlapping methods, not 41 distinct proven winners.
4. Offer a few genuinely different hooks when useful, select one and deliver the full requested draft. Use accessible paragraphs, early payoff and a close that fits the content; do not force a question or personal confession.
5. For repurposing, extract standalone claims, mechanisms, stories and examples. Preserve source qualifications and attribution; vary the angles without multiplying a thin source into empty posts.
6. Pass the output through linkedin-quality. Return copy-ready text, supporting sources and a character count when relevant. A writing request does not invoke publishing.

## Deliverable

Requested finished draft(s), optional hook options, source notes and any unresolved factual gap clearly outside final copy.
