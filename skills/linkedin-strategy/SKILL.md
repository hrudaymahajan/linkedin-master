# Content strategy and team programs

Use the shared scope and factual rules in the [master skill](../../SKILL.md).
This module can be read directly but requires the repository references.

## Inputs

Audience, goal, available material, effort and planning period; team context only for a team program.

## Workflow

1. Read existing audience, voice, recent content and performance information. Ask only for consequential gaps.
2. For competitor or topic analysis, compare a bounded set of observed posts by theme, format and available outcomes; label correlations and missing data.
3. Select angles with a concrete takeaway and available evidence. Mix relevant themes without manufacturing personal stories or forcing generic sales quotas.
4. For a calendar, assign angle, source, format, hook direction, goal and an audience-timezone-aware proposed time when useful. A plan does not create a scheduler.
5. For employee advocacy, collect individual expertise and voluntary cadence; define voice capture, first drafts, idea supply, factual review and measurement. Preserve individual voices instead of distributing identical copy.
6. Return the requested plan and identify which drafts can be produced now. Complete requested drafts through the writing module instead of adding unnecessary approval rounds.

## Deliverable

Calendar or strategy brief; team requests also receive responsibilities, review boundaries and a measurable operating plan.
