# Voice, interviewing, editing and audits

Use the shared scope and factual rules in the [master skill](../../SKILL.md).
This module can be read directly but requires the repository references.

## Inputs

Draft or actual writing samples; requested mode: interview, voice, rewrite, audit, emoji review, rule explanation or detector comparison.

## Workflow

1. For voice, infer style only from actual samples or explicit preferences. Keep how the user writes separate from confirmed biographical facts. Do not treat a source author's style as the user's voice.
2. For an interview, pursue concrete moments, evidence and useful lessons, clarify vague claims once and respect off-limit subjects. Summarize confirmed facts and gaps; store private material only in an appropriate user-owned location, never the distributable skill.
3. For editing, remove filler, repetition, unsupported claims, accidental template markers and forced suspense. Preserve meaning, uncertainty, attribution and technical vocabulary. Review paragraph rhythm proportionately rather than mechanically changing punctuation or sentence lengths.
4. For an audit, inspect factual support, audience fit, hook payoff, structure, accessibility and requested format. Separate real blockers from optional style preferences. Review-only requests get findings and suggested fixes; rewrite requests get revised text.
5. For emoji review, examine repetition, distraction and accessibility against the user's style. A particular emoji is not proof of AI authorship. For rule explanation, distinguish accidental artifacts, user preferences and aesthetic judgments.
6. For detector comparison, explain limitations first. Only use real, available detector services for a specifically requested comparison with the required data-sharing authorization. Label provider outputs and disagreement; never present demo values as measurements or promise undetectability.
7. Recheck that edits introduced no invented metric, event, claim or awkward pattern. Deliver clean copy and a concise account of meaningful changes; leave already effective prose alone.

## Deliverable

Voice profile, confirmed story notes, revised text or audit findings as requested; any scores explicitly identified as editorial heuristics.
